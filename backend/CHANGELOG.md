# API 变更记录

## 3.1.0

- 提供站点展示、关于资料、项目封面和公告设置的完整数据契约。
- 提供文章附件上传、关联、下载和媒体引用保护。
- 提供评论分页与仅管理员可读取的评论邮箱。
- 批量读取文章标签，保持列表查询数量稳定。
- 建立文章发布、附件、评论和站点展示的数据库集成验收。
- 建立访问日志采集、同页去重、限频、7/30/90 天聚合及管理员 IP 明细接口。
- 建立访问记录 90 天自动清理与统计权限验收；当前未接入 IP 归属地数据库。

## 3.0.2

- 允许配置的本地前端来源访问 API，修复文章分页等客户端请求被浏览器跨域策略拦截。

## 3.0.1

- 按文件格式返回图片和音频的媒体类型，确保浏览器能正确识别本地媒体。

## 3.0.0

- 将登录和会话认证限制为配置的唯一管理员账号。
- 移除重复的文章归档统计接口。

## 2.0.0

- 移除公开曲目读取及后台音乐管理接口。
- 停止接收新的音频文件上传，并通过数据库迁移移除曲目表。

## 1.1.0

- 增加管理员登录、会话撤销、文章草稿发布、软删除和分类标签管理。
- 增加游客评论审核、站点设置、关于、项目、收藏和友链管理接口。
- 增加媒体上传、引用保护和 Swagger API 文档。
- 修复媒体引用检查的 SQL 参数绑定错误。

## 1.0.0

- 初始化独立的博客 API 服务。
- 提供文章检索、分类与标签读取及健康检查接口。
- 集成 OpenAPI 规范和 Swagger UI。
