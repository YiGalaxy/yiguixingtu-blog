# API 变更记录

## 3.0.2

- 允许配置的本地前端来源访问 API，修复文章分页等客户端请求被浏览器跨域策略拦截。

## 3.0.1

- 按文件格式返回图片和音频的媒体类型，确保浏览器能正确识别本地媒体。

## 3.0.0

- 将登录和会话认证限制为配置的唯一管理员账号。
- 移除重复的文章归档统计接口。

## 2.0.0

- 移除公开曲目读取及后台音乐管理接口。
- 停止接收新的音频文件上传，并通过数据库迁移移除曲目表。

## 1.1.0

- 增加管理员登录、会话撤销、文章草稿发布、软删除和分类标签管理。
- 增加游客评论审核、站点设置、关于、项目、收藏和友链管理接口。
- 增加媒体上传、引用保护和 Swagger API 文档。
- 修复媒体引用检查的 SQL 参数绑定错误。

## 1.0.0

- 初始化独立的博客 API 服务。
- 提供文章检索、分类与标签读取及健康检查接口。
- 集成 OpenAPI 规范和 Swagger UI。
