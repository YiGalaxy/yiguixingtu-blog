## 管理与发布

后台默认进入文章管理，保留文章、分类、标签、评论、项目、收藏、友链、关于、存储、设置和概览。仅配置的管理员可以登录；受保护接口在没有有效会话时拒绝访问。

- 文章：关键词、分类、状态筛选与分页；弹窗 Markdown 双栏编辑；封面、标签、置顶、草稿、发布、正文图片和附件。已完成真实浏览器发布后回读和编辑器手机布局检查。
- 评论：游客提交后本人看到待审核反馈，公开列表不显示未审内容；管理员审核通过后公开展示，后台可按状态筛选和删除。邮箱只由后台接口返回。已走通提交、刷新、审核、公开回读与删除流程。
- 展示：关于资料、项目封面与技术栈、收藏分组、友链和备案可在后台维护。
- 媒体：上传、按格式读取、文档下载、文件数与容量显示，删除前检查文章、附件、项目和站点展示引用。
- 概览：已发布文章汇总、近期文章、访问趋势、PV/UV、保留期内首次访客、来源、身份、设备、页面和文章排行。IP 弹窗按需读取，支持近 7/30/90 天切换。

## 图片和附件存储

图片与附件作为文件保存在 `BLOG_UPLOAD_DIR` 指定的目录，当前为 `backend/uploads`；数据库保存文章正文中的媒体 URL、封面 URL 和附件名称、URL、大小等关联信息，不保存图片二进制。

上传生成独立文件名，浏览器从 `/api/v1/media/{filename}` 读取。图片在编辑器光标处插入 Markdown，文章附件单独关联，文档以附件方式下载。存在引用的文件不能直接从后台删除；移除文章中的引用后，可在存储管理中清理。目录已从 Git 排除。

正式部署必须持久化并备份整个上传目录，同时备份数据库；恢复时二者配套。切换生产域名时，还需将本地预览 URL 转换为生产媒体 URL 并检查反向代理转发协议和主机名。

## 访问统计口径和限制

访问数据从当前预览开始新采集，没有导入线上私密访问日志。按 UTC 日期统计；UV 按 IP 去重，首次访客指保留期内该 IP 最早出现，不能当作永久唯一读者数。同一 IP 五秒内重复打开同一路径只记一次，每 IP 每分钟最多接收 120 次。

原始记录保留 90 天，每日自动清理。仅采集保留的公开页面；查询条件变化不另记一次页面访问。IP 明细只允许管理员读取，最多返回 200 条。当前未接入 IP 归属地数据库，归属地显示「—」。生产环境需由可信反向代理覆盖转发头，并限制 API 的直接入口，保证 IP 口径正确。
