# 网站变更记录

## 3.1.0

- 建立与旧站一致的七类公开页面、昼夜场景、像素导航和响应式布局。
- 实现首页筛选与增量加载、文章列表分页和浏览器前进后退状态同步。
- 提供 Markdown 阅读、目录定位、代码复制折叠、图片预览与文章附件下载。
- 建立独立游客评论区和私有待审核反馈。
- 提供后台侧栏、Markdown 双栏编辑器、正文图片上传与附件编辑。
- 展示完整站长资料、项目封面、收藏分组与备案信息。
- 提供文章关键词、分类、状态筛选与后台分页，以及评论审核与删除操作。
- 建立访问趋势、PV/UV、访客构成、页面和文章排行及访客 IP 弹窗，支持昼夜主题和手机布局。
- 展示上传文件总数与已用容量。

## 3.0.0

- 在文章编辑器中上传图片并于光标位置插入 Markdown 图片。
- 后台仅提供管理员登录，不提供用户管理入口。
- 移除归档页面、页脚入口和站点地图地址，文章列表继续提供文章检索。

## 2.0.0

- 移除音乐页面、导航入口和后台曲目管理。
- 从首页站点概览移除音乐入口。
- 从站点地图中移除音乐页面地址。

## 1.3.0

- 恢复旧站 Minecraft 像素风格，包括昼夜背景、品牌素材、图标图集和方块式控件。
- 将首页恢复为个人头像、站点数据和文章搜索布局。

## 1.2.0

- 重做前台视觉系统，采用编辑部式排版、朱红与酸橙绿强调色及响应式首页布局。
- 将后台入口调整为站长登录入口，保持阅读与管理入口边界清晰。

## 1.1.0

- 收拢首页与文章检索职责，保留旧筛选链接并重定向到文章页。
- 完成文章、归档、项目、关于、收藏、友链和音乐页面及站点管理入口。
- 增加 RSS、站点地图和 robots.txt 服务端路由。
- 后台默认进入文章管理，并按内容、展示、站点和概览组织业务入口。

## 1.0.0

- 初始化独立的网站应用。
- 建立首页、文章检索、项目、关于和站点管理入口。
- 将首页搜索和旧筛选链接统一导向文章检索页。
